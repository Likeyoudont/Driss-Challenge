# MoGo — Frontend Challenge Project

An implementation of the MoGo PSD design using HTML, CSS,
Bootstrap, and JavaScript.

## Purpose

I built this project as a challenge to practice translating a visual design
into a website. I used Photoshop to measure spacing, typography,
and element dimensions. 

## Technologies

- HTML
- CSS
- Bootstrap
- JavaScript

## Project structure

- Mogo/Mogo-project/Mogo.html — main page
- Mogo/Mogo-project/css-files/ — separate stylesheets
- Mogo/Mogo-project/js-file/ — scripts
- Mogo/Mogo-project/photos/ — images grouped by section

## Run locally

Download or clone the repository, then open
Mogo/Mogo-project/Mogo.html in a browser.

An internet connection is needed for external fonts,
icons, Bootstrap, and some JavaScript dependencies.

## Status

Work in progress. The sections are combined into one page.
JavaScript interactions are being developed and debugged.
Responsive behavior and accessibility still need full testing.
